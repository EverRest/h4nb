# h4nb — CUDA Hermite-4 N-body Library Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `h4nb`, a C++17/CUDA library for direct N-body simulation. It uses the 4th-order Hermite integrator with Aarseth block time steps in FP64. It runs on one or more NVIDIA GPUs. The target is N = 128k to 1,024k particles plus one heavy central body that moves.

**Architecture:** The library has one public header (`include/h4nb/h4nb.hpp`) and one class, `Simulation`. The per-particle math is in one `__host__ __device__` header (`src/hermite.cuh`). The GPU kernels and the CPU reference in the tests use this header. So the GPU result can be compared with an oracle that runs the same code. For multi-GPU, the **sources** (j-particles) are split across the GPUs. All active **targets** (i-particles) go to every GPU. Each owner GPU then adds the partial forces in a fixed order. One GPU is the case G = 1 of the same code.

**Tech Stack:** C++17, CUDA ≥ 12.0 (CUB and Thrust come with the toolkit), CMake ≥ 3.24, CTest. The tests are plain executables with CHECK and CHECK_NEAR macros. There is no other dependency.

**Spec:** `docs/superpowers/specs/2026-11-07-h4nb-tz-original.md`. This is the original technical specification (TZ). It is in Ukrainian and was copied word for word from the user's ChatGPT conversation. Read it together with this plan. Where this plan differs from the TZ, the reason is in **Design decisions** below.

## Global Constraints

- The language is C++17 and CUDA C++17. Use CMake ≥ 3.24. `CMAKE_CUDA_ARCHITECTURES` defaults to `native`.
- **The build and the GPU tests need Linux with an NVIDIA GPU and CUDA ≥ 12.0.** The user's Mac cannot run CUDA code. The Mac can compile the code in the CUDA container (see the quickstart). A compile on the Mac proves only that the code compiles.
- Use FP64 for all physical values: positions, velocities, masses, accelerations, jerks, steps and energy. Do not use `float` in the force path (TZ 4.4).
- **Never** use `--use_fast_math` or `-ffast-math`. The NaN and Inf checks use IEEE operations that fast-math breaks.
- Do not use floating-point atomics. Every sum has a fixed order, so a run is bitwise reproducible for the same N, device list and build (TZ requirement 13). Integer atomics are allowed: `atomicOr` for status bits and `atomicMin` on the bit pattern of a non-negative double.
- Softening is optional. The default is `eps2 = 0`. Softening is not a method to reach energy accuracy (TZ 2.1).
- The central body is particle index 0. It is a full N-body participant. `fixed_center` is only for tests and comparisons (TZ 2.2).
- The energy target is max |ΔE/E₀| ≤ 1e-8 over one mean orbital period. The acceptance run (Task 7) must show this. A config value cannot replace the measurement (TZ 12, row 6).
- The only dependencies are the CUDA toolkit (CUB, Thrust) and the C++ standard library. Do not add other dependencies.
- The user's rules (`~/.claude/CLAUDE.md`): **do not commit, push or amend unless the user asks.** Keep diffs small. If a shortcut has real consequences, ask the user first.
- Constitution 1.1.0 (`.specify/memory/constitution.md`): the tests are in `tests/`. The label `cpu` marks the tests that run without a GPU. The label `gpu` marks the tests that need a GPU. A failing test is a finding. The thresholds of a test must not be loosened.

## Design decisions (deviations from the TZ, with reasons)

| # | Decision | Why |
|---|---|---|
| D1 | This is a **library**: a `Config` struct and a `Simulation` class. There is no INI parser. The tool `tools/h4nb_run` writes the `.dat` files of TZ 10.3. | The user asked for a library. Configuration files belong to the application. |
| D2 | **Multi-GPU is j-parallel.** Each GPU owns N/G particles. It holds their full state, and it is the only GPU that predicts and corrects them. For each block step, the active targets are all-gathered. Each GPU computes the partial force of its sources on all targets. Each owner adds the partials for its own targets in device order. TZ 5.1 proposed replicated sources with split targets instead. | In block steps, N_active is usually 10²–10⁴. With split targets, each GPU gets too few threads. With split sources, each GPU does exactly N_active·N/G pair evaluations. So the **load is balanced by design**, and TZ 5.3 "dynamic balancing" needs no code. The traffic for each step is O(N_active). |
| D3 | The code uses one process on one node. It copies data with `cudaMemcpyAsync(..., cudaMemcpyDefault, stream)` and enables peer access where it can. It does not use MPI or NCCL. | YAGNI. Add MPI when the user needs more than one node. |
| D4 | Time is stored as **int64 ticks**: `tick = dt_max / 2^max_level`. Level k has a step of `2^(max_level-k)` ticks. | Block times are then exact. "Is it active?" is an integer comparison, and the run is deterministic. |
| D5 | Snap is moved to t₁ (`s₁ = s₀ + c·h`) before the Aarseth criterion is applied. The first step is `eta_init·|a|/|j|`. A particle can go to a smaller level (a finer step) at any time. It can go up only one level, and only when t is a multiple of the new step. | The formulas in TZ 3.5 give the snap at t₀. A block scheme needs these rules. |
| D6 | The potential is computed on the GPU over **unique pairs j>i** (TZ 8.3). K, P, L and the final sums are computed on the host with Neumaier summation. Diagnostics run only at **sync points** (multiples of `dt_max`). At these times all particles have t = T. | The N² part runs on the GPU. The O(N) part is cheap on the host, and its order is fixed. A predicted state would add predictor error to E. |
| D7 | The predictor is a separate kernel. It runs over all owned particles at each block step. It is not fused into the force kernel. | It is simpler and easy to check. The estimated cost is ≤ 5 % of a step. See gated optimisation O1. |
| D8 | The encounter control (TZ 7.1) records r²_min per target in the force kernel. Status bits are `kClosePair`, `kDtUnderflow` and `kNaN`. `kNaN` also covers Inf. There is no regularisation (TZ 15.3 defers it). | It costs one `fmin` per pair. |
| D9 | `performance.dat` contains: wall time, block steps, active count and pairs per second for each output interval. It does not contain separate kernel and transfer times for each GPU. | Use `nsys` to get those. Add event timers only if the user asks for them. |
| D10 | The TZ's "Mode A, global step" is `StepMode::Fixed` (all particles use `dt_max/2^fixed_level`). It is used for convergence checks and P checks. | A fixed shared step gives a clean 4th-order convergence test (TZ 11.6). |
| D11 | **η finding:** a Python model of this exact algorithm shows that a two-body orbit needs η ≈ 5e-4 to reach 1e-8 per orbit. With η = 0.001, the error is 1.2–2.1e-8. The TZ range 0.001–0.02 is too coarse. | The number of steps grows as 1/√η. The user must be told. Task 7 measures the value of η for the real disk. Open: user decision on the default `Config::eta` (currently 0.01). |

### Cost model (an estimate; check it with `h4nb_bench`)

- One full force pass at N = 1,024,000 is 1.05e12 pairs × about 60 FP64 FLOP = 6.3e13 FLOP. The time is about **3.5 s** on an H100 SXM, about 12 s on an A100 and about 90 s on an RTX 4090 (FP64 is 1/64 of FP32 there).
- With η = 5e-4, a circular orbit takes 2π/√η ≈ 280 steps. One mean period at 1M particles is then about 280·N² ≈ 3e14 pairs. That is about **16 min on one H100**, or about 7 h on an RTX 4090. Inner orbits cost more.
- One energy check is N²/2 pairs (about 0.5–1 s on an H100). Set the `diag` interval with this cost in mind.

### Open questions (they do not block Tasks 1–6)

1. Which GPUs are the targets: H100/A100 class or RTX class? This decides if gated optimisation O5 (mixed precision) is needed.
2. Are the GPUs in one node or in a cluster? This decides if O7 (MPI) is needed. Open: user decision.
3. Which "mean period" is the acceptance period: the mean, the median or the mass-weighted mean (TZ 6.3)? `h4nb_mkdisk` prints all three. The quickstart uses the mean.
4. Is ε = 0 mandatory for the 1M runs? Close encounters without softening push dt to `dt_min`, and the run stalls. Regularisation (O8) is the fix. Open: user decision.

### Changes after the first draft

- **r_min:** `Stats::min_r2` holds the smallest r² between a target and its closest source over the run. `stats()` reads it from the GPUs. `h4nb_run` writes `sqrt(min_r2)` as the last column of `timesteps.dat`. A warning appears when `kClosePair` is set.
- **Default close-pair radius:** `h4nb_run` uses `r_close = 0.1 · R_rms / N^(1/3)` when `r_close` is not set. R_rms is the rms radius of the initial state. `r_close=0` turns the check off. Open: user decision on this default.
- **NaN and Inf:** `h4_nonfinite(x)` tests `!(x - x == 0)`. This is true for NaN and for Inf. It is used for the acceleration, the jerk and the position and velocity sums. The status bit is still called `kNaN`.
- **Benchmark:** `h4nb_bench` counts `blocks` and `step_pair/s` from the state after the first force pass. The first force pass is not part of the step rate.

// h4nb: direct N-body library. 4th-order Hermite integrator, Aarseth block time steps, FP64, one or more NVIDIA GPUs.
#pragma once
#include <cstdint>
#include <memory>
#include <string>
#include <vector>

namespace h4nb {

// Host particle set, structure of arrays. Index 0 is the central body.
struct Particles {
  std::vector<int64_t> id;
  std::vector<double> m, x, y, z, vx, vy, vz;
  size_t size() const { return m.size(); }
  void resize(size_t n) {
    id.resize(n); m.resize(n); x.resize(n); y.resize(n); z.resize(n); vx.resize(n); vy.resize(n); vz.resize(n);
  }
};

enum class StepMode { Block, Fixed };

// Bits returned by Simulation::status(). Once set, a bit stays set.
enum StatusBits : unsigned { kNaN = 1u, kDtUnderflow = 2u, kClosePair = 4u };

struct Config {
  double G = 1.0;
  double eps2 = 0.0;          // Plummer softening squared; 0 = Newtonian gravity (default)
  double eta = 0.01;          // Aarseth accuracy parameter
  double eta_init = 0.01;     // first step: dt = eta_init * |a| / |j|
  double dt_max = 1.0 / 64;   // step of level 0; advance_to() times must be multiples of it
  int max_level = 40;         // dt_min = dt_max / 2^max_level; at most 50
  StepMode mode = StepMode::Block;
  int fixed_level = 0;        // Fixed mode: every particle uses dt_max / 2^fixed_level
  bool fixed_center = false;  // particle 0 does not move (comparisons and acceptance runs only)
  double r2_close = 0.0;      // set kClosePair when a pair has r^2 < r2_close (0 = off)
  std::vector<int> devices = {0};  // CUDA device ids; a repeated id emulates more GPUs on one card
};

struct Diagnostics {
  double time = 0, K = 0, U = 0, E = 0;
  double P[3] = {0, 0, 0}, L[3] = {0, 0, 0};
};

struct Stats {
  int64_t block_steps = 0;   // number of block steps done
  int64_t active_total = 0;  // sum of active particles over all block steps; pair evaluations = active_total * N
};

class Simulation {
 public:
  Simulation(const Particles& p, const Config& c);  // uploads, computes a and j, picks the first steps
  ~Simulation();
  Simulation(const Simulation&) = delete;
  Simulation& operator=(const Simulation&) = delete;

  void advance_to(double t);        // t: multiple of dt_max, >= time(); all particles are synchronized at t on return
  double time() const;
  Particles state() const;          // positions and velocities at time()
  std::vector<int> levels() const;  // block level of each particle
  Diagnostics diagnostics();        // K, U, E, P, L at time(); U costs N^2/2 pair evaluations
  unsigned status() const;          // StatusBits
  Stats stats() const;

 private:
  struct Impl;
  std::unique_ptr<Impl> impl_;
};

Particles load_text(const std::string& path);  // lines "id m x y z vx vy vz"; a line that starts with '#' is a comment
void write_snapshot(const std::string& path, const Particles& p, double time);
Particles read_snapshot(const std::string& path, double* time = nullptr);

}  // namespace h4nb

`src/hermite.cuh`:

```cpp
// Per-particle Hermite math. __host__ __device__ so the CPU oracle in tools runs exactly the GPU code.
#pragma once
#include <math.h>
#include <cmath>
#include <cstdint>
#include "h4nb/h4nb.hpp"

#ifdef __CUDACC__
#define H4_HD __host__ __device__ inline
#else
#define H4_HD inline
#endif

namespace h4nb {

struct alignas(32) d4 { double x, y, z, w; };  // positions: w = mass; other vectors: w unused (0)

H4_HD double h4_rsqrt(double x) {
#ifdef __CUDA_ARCH__
  return ::rsqrt(x);
#else
  return 1.0 / std::sqrt(x);
#endif
}
// NaN and Inf: x - x is NaN for both, and NaN == 0 is false. Valid because fast-math is banned.
H4_HD bool h4_nonfinite(double x) { return !(x - x == 0); }
H4_HD double norm3(const d4& u) { return ::sqrt(u.x * u.x + u.y * u.y + u.z * u.z); }

// Taylor predictor (TZ 3.2). Keeps xp.w = mass.
H4_HD void predict(const d4& x, const d4& v, const d4& a, const d4& j, double dt, d4& xp, d4& vp) {
  const double h2 = 0.5 * dt * dt, h3 = h2 * dt * (1.0 / 3.0);
  xp = d4{x.x + v.x * dt + a.x * h2 + j.x * h3, x.y + v.y * dt + a.y * h2 + j.y * h3,
          x.z + v.z * dt + a.z * h2 + j.z * h3, x.w};
  vp = d4{v.x + a.x * dt + j.x * h2, v.y + a.y * dt + j.y * h2, v.z + a.z * dt + j.z * h2, 0.0};
}

struct AJ {
  double ax = 0, ay = 0, az = 0, jx = 0, jy = 0, jz = 0;
  double r2min = 1e300;  // closest source seen (TZ 7.1)
};

// Adds the pull of source (xj, vj; mass xj.w) on target (xi, vi) (TZ 3.3). The caller skips i == j. G is applied later.
H4_HD void accumulate(AJ& f, const d4& xi, const d4& vi, const d4& xj, const d4& vj, double eps2) {
  const double dx = xj.x - xi.x, dy = xj.y - xi.y, dz = xj.z - xi.z;
  const double dvx = vj.x - vi.x, dvy = vj.y - vi.y, dvz = vj.z - vi.z;
  const double r2 = dx * dx + dy * dy + dz * dz;
  f.r2min = ::fmin(f.r2min, r2);
  const double rinv = h4_rsqrt(r2 + eps2);
  const double rinv2 = rinv * rinv;
  const double mr3 = xj.w * rinv * rinv2;
  const double alpha = 3.0 * (dx * dvx + dy * dvy + dz * dvz) * rinv2;
  f.ax += mr3 * dx;
  f.ay += mr3 * dy;
  f.az += mr3 * dz;
  f.jx += mr3 * (dvx - alpha * dx);
  f.jy += mr3 * (dvy - alpha * dy);
  f.jz += mr3 * (dvz - alpha * dz);
}

// Aarseth criterion for 4th-order Hermite (TZ 3.6).
H4_HD double aarseth_dt(double a, double j, double s, double c, double eta) {
  return ::sqrt(eta * (a * s + j * j) / (j * c + s * s));
}

// Hermite corrector (TZ 3.4, Makino & Aarseth 1992). Updates x, v (not x.w). Returns the Aarseth step at t1.
H4_HD double correct(d4& x, d4& v, const d4& a0, const d4& j0, const d4& a1, const d4& j1, double h, double eta) {
  const double c12 = h * h * (1.0 / 12.0);
  const d4 vn{v.x + 0.5 * (a0.x + a1.x) * h + (j0.x - j1.x) * c12,
              v.y + 0.5 * (a0.y + a1.y) * h + (j0.y - j1.y) * c12,
              v.z + 0.5 * (a0.z + a1.z) * h + (j0.z - j1.z) * c12, 0.0};
  x.x += 0.5 * (v.x + vn.x) * h + (a0.x - a1.x) * c12;
  x.y += 0.5 * (v.y + vn.y) * h + (a0.y - a1.y) * c12;
  x.z += 0.5 * (v.z + vn.z) * h + (a0.z - a1.z) * c12;
  v = vn;
  // TZ 3.5 gives snap at t0; the criterion needs it at t1: s1 = s0 + c h.
  const double ih = 1.0 / h, ih2 = ih * ih, ih3 = ih2 * ih;
  const d4 s0{(-6.0 * (a0.x - a1.x) - h * (4.0 * j0.x + 2.0 * j1.x)) * ih2,
              (-6.0 * (a0.y - a1.y) - h * (4.0 * j0.y + 2.0 * j1.y)) * ih2,
              (-6.0 * (a0.z - a1.z) - h * (4.0 * j0.z + 2.0 * j1.z)) * ih2, 0.0};
  const d4 cr{(12.0 * (a0.x - a1.x) + 6.0 * h * (j0.x + j1.x)) * ih3,
              (12.0 * (a0.y - a1.y) + 6.0 * h * (j0.y + j1.y)) * ih3,
              (12.0 * (a0.z - a1.z) + 6.0 * h * (j0.z + j1.z)) * ih3, 0.0};
  const d4 s1{s0.x + cr.x * h, s0.y + cr.y * h, s0.z + cr.z * h, 0.0};
  return aarseth_dt(norm3(a1), norm3(j1), norm3(s1), norm3(cr), eta);
}

// Block level for a wanted step. Level k = step dt_max / 2^k = 2^(max_level-k) ticks.
// May go to any finer level. May go up only one level, and only when t is aligned to the coarser step.
H4_HD int choose_level(double dt_want, double dt_max, int k_old, int64_t t_ticks, int max_level, bool& underflow) {
  int k = 0;
  double d = dt_max;
  while (d > dt_want && k < max_level) {
    d *= 0.5;
    ++k;
  }
  if (d > dt_want) underflow = true;  // dt_min is still too large (TZ 7.1)
  if (k < k_old) {
    k = k_old - 1;
    if (t_ticks % (int64_t(1) << (max_level - k)) != 0) k = k_old;
  }
  return k;
}

struct StepParams {
  int64_t T;  // block time of this step, ticks
  double tick, dt_max, eta, eta_init, G, r2_close;
  int max_level;
  int fixed_level;  // >= 0: Fixed mode; -1: adaptive
  bool init;        // first force evaluation: no corrector
};

inline StepParams make_params(const Config& c, double tick, int64_t T, bool init) {
  return StepParams{T, tick, c.dt_max, c.eta, c.eta_init, c.G, c.r2_close, c.max_level,
                    c.mode == StepMode::Fixed ? c.fixed_level : -1, init};
}

// Applies the new force (a1, j1, already times G) to one active particle. Returns StatusBits.
H4_HD unsigned update_particle(const StepParams& p, bool is_center, d4 a1, d4 j1, double r2min, d4& x, d4& v, d4& a,
                               d4& j, int64_t& t, int64_t& next, int& level) {
  unsigned st = 0;
  if (r2min < p.r2_close) st |= kClosePair;
  if (h4_nonfinite(a1.x + a1.y + a1.z + j1.x + j1.y + j1.z)) st |= kNaN;
  bool under = false;
  int lv;
  if (is_center) {
    a = d4{0, 0, 0, 0};
    j = d4{0, 0, 0, 0};
    lv = p.fixed_level >= 0 ? p.fixed_level : 0;
  } else if (p.init) {
    a = a1;
    j = j1;
    lv = p.fixed_level >= 0 ? p.fixed_level
                            : choose_level(p.eta_init * norm3(a1) / norm3(j1), p.dt_max, 0, p.T, p.max_level, under);
  } else {
    const double dtw = correct(x, v, a, j, a1, j1, double(p.T - t) * p.tick, p.eta);
    a = a1;
    j = j1;
    lv = p.fixed_level >= 0 ? p.fixed_level : choose_level(dtw, p.dt_max, level, p.T, p.max_level, under);
    if (h4_nonfinite(x.x + x.y + x.z + v.x + v.y + v.z)) st |= kNaN;
  }
  if (under) st |= kDtUnderflow;
  level = lv;
  t = p.T;
  next = p.T + (int64_t(1) << (p.max_level - lv));
  return st;
}

Snapshot layout: a 32-byte header (`"H4NBSNAP"`, uint32 version = 1, uint32 reserved, uint64 n, double time), then 8 arrays of n 8-byte values in this order: `id, m, x, y, z, vx, vy, vz`. Array k starts at byte `32 + 8·n·k`. A reader can therefore load one array only.

```cpp
#include <cstring>
#include <fstream>
#include <sstream>
#include <stdexcept>
#include "h4nb/h4nb.hpp"

namespace h4nb {
namespace {
struct Header {
  char magic[8];
  uint32_t version;
  uint32_t reserved;
  uint64_t n;
  double time;
};
static_assert(sizeof(Header) == 32, "snapshot header must be 32 bytes");
constexpr char kMagic[8] = {'H', '4', 'N', 'B', 'S', 'N', 'A', 'P'};
}  // namespace

Particles load_text(const std::string& path) {
  std::ifstream f(path);
  if (!f) throw std::runtime_error("cannot open " + path);
  Particles p;
  std::string line;
  for (int ln = 1; std::getline(f, line); ++ln) {
    const size_t s = line.find_first_not_of(" \t\r");
    if (s == std::string::npos || line[s] == '#') continue;
    std::istringstream is(line);
    int64_t id;
    double m, x, y, z, vx, vy, vz;
    if (!(is >> id >> m >> x >> y >> z >> vx >> vy >> vz))
      throw std::runtime_error(path + ":" + std::to_string(ln) + ": expected 'id m x y z vx vy vz'");
    p.id.push_back(id); p.m.push_back(m);
    p.x.push_back(x); p.y.push_back(y); p.z.push_back(z);
    p.vx.push_back(vx); p.vy.push_back(vy); p.vz.push_back(vz);
  }
  return p;
}

void write_snapshot(const std::string& path, const Particles& p, double time) {
  std::ofstream f(path, std::ios::binary);
  if (!f) throw std::runtime_error("cannot write " + path);
  Header h{};
  std::memcpy(h.magic, kMagic, 8);
  h.version = 1;
  h.n = p.size();
  h.time = time;
  f.write(reinterpret_cast<const char*>(&h), sizeof h);
  auto put = [&](const auto& v) { f.write(reinterpret_cast<const char*>(v.data()), std::streamsize(v.size() * 8)); };
  put(p.id); put(p.m); put(p.x); put(p.y); put(p.z); put(p.vx); put(p.vy); put(p.vz);
  if (!f) throw std::runtime_error("write failed: " + path);
}

Particles read_snapshot(const std::string& path, double* time) {
  std::ifstream f(path, std::ios::binary);
  if (!f) throw std::runtime_error("cannot open " + path);
  Header h{};
  f.read(reinterpret_cast<char*>(&h), sizeof h);
  if (!f || std::memcmp(h.magic, kMagic, 8) != 0 || h.version != 1)
    throw std::runtime_error(path + ": not an h4nb v1 snapshot");
  Particles p;
  p.resize(h.n);
  auto get = [&](auto& v) { f.read(reinterpret_cast<char*>(v.data()), std::streamsize(v.size() * 8)); };
  get(p.id); get(p.m); get(p.x); get(p.y); get(p.z); get(p.vx); get(p.vy); get(p.vz);
  if (!f) throw std::runtime_error(path + ": truncated snapshot");
  if (time) *time = h.time;
  return p;
}

}  // namespace h4nb

#include <cmath>

// Relative Kepler orbit at time t. Pericentre on +x at t = 0, motion towards +y.
inline void kepler_rel(double mu, double a, double e, double t, double r[3], double v[3]) {
  const double n = std::sqrt(mu / (a * a * a));
  const double M = n * t;
  double E = M;
  for (int it = 0; it < 50; ++it) E -= (E - e * std::sin(E) - M) / (1.0 - e * std::cos(E));
  const double c = std::cos(E), s = std::sin(E), b = a * std::sqrt(1.0 - e * e), Ed = n / (1.0 - e * c);
  r[0] = a * (c - e); r[1] = b * s; r[2] = 0.0;
  v[0] = -a * s * Ed; v[1] = b * c * Ed; v[2] = 0.0;
}

// CPU oracle: the same block-step algorithm as the GPU library, O(N^2) per step. Use for small N only.
#pragma once
#include <algorithm>
#include <cmath>
#include <vector>
#include "hermite.cuh"

namespace ref {
using h4nb::d4;

class Ref {
 public:
  Ref(const h4nb::Particles& p, const h4nb::Config& c)
      : c_(c), n_(int(p.size())), tick_(c.dt_max / std::ldexp(1.0, c.max_level)), id_(p.id), x_(n_), v_(n_),
        a_(n_), j_(n_), t_(n_, 0), next_(n_, 0), level_(n_, 0) {
    for (int i = 0; i < n_; ++i) {
      x_[i] = d4{p.x[i], p.y[i], p.z[i], p.m[i]};
      v_[i] = d4{p.vx[i], p.vy[i], p.vz[i], 0.0};
    }
    if (c_.fixed_center) v_[0] = d4{0, 0, 0, 0};
    step(true);
  }
  void advance_to(double t) {
    const int64_t target = int64_t(std::llround(t / c_.dt_max)) << c_.max_level;
    while (T_ < target) step(false);
  }
  double time() const { return double(T_) * tick_; }
  h4nb::Particles state() const {
    h4nb::Particles p;
    p.resize(size_t(n_));
    p.id = id_;
    for (int i = 0; i < n_; ++i) {
      p.m[i] = x_[i].w; p.x[i] = x_[i].x; p.y[i] = x_[i].y; p.z[i] = x_[i].z;
      p.vx[i] = v_[i].x; p.vy[i] = v_[i].y; p.vz[i] = v_[i].z;
    }
    return p;
  }
  std::vector<int> levels() const { return level_; }
  unsigned status() const { return status_; }

 private:
  void step(bool init) {
    const int64_t Tn = init ? 0 : *std::min_element(next_.begin(), next_.end());
    std::vector<d4> xp(n_), vp(n_);
    for (int i = 0; i < n_; ++i) h4nb::predict(x_[i], v_[i], a_[i], j_[i], double(Tn - t_[i]) * tick_, xp[i], vp[i]);
    std::vector<int> act;
    for (int i = 0; i < n_; ++i)
      if (next_[i] == Tn) act.push_back(i);
    std::vector<h4nb::AJ> f(act.size());  // all forces first, then all updates (as on the GPU)
    for (size_t k = 0; k < act.size(); ++k)
      for (int s = 0; s < n_; ++s)
        if (s != act[k]) h4nb::accumulate(f[k], xp[act[k]], vp[act[k]], xp[s], vp[s], c_.eps2);
    const h4nb::StepParams p = h4nb::make_params(c_, tick_, Tn, init);
    for (size_t k = 0; k < act.size(); ++k) {
      const int i = act[k];
      const d4 a1{c_.G * f[k].ax, c_.G * f[k].ay, c_.G * f[k].az, 0.0};
      const d4 j1{c_.G * f[k].jx, c_.G * f[k].jy, c_.G * f[k].jz, 0.0};
      status_ |= h4nb::update_particle(p, c_.fixed_center && i == 0, a1, j1, f[k].r2min, x_[i], v_[i], a_[i], j_[i],
                                       t_[i], next_[i], level_[i]);
    }
    T_ = Tn;
  }

  h4nb::Config c_;
  int n_;
  double tick_;
  std::vector<int64_t> id_;
  std::vector<d4> x_, v_, a_, j_;
  std::vector<int64_t> t_, next_;
  std::vector<int> level_;
  int64_t T_ = 0;
  unsigned status_ = 0;
};

// Direct O(N^2) energy, momentum and angular momentum.
inline h4nb::Diagnostics direct_diagnostics(const h4nb::Particles& p, double G, double eps2) {
  h4nb::Diagnostics d;
  const size_t n = p.size();
  double U = 0;
  for (size_t i = 0; i < n; ++i) {
    const double m = p.m[i];
    d.K += 0.5 * m * (p.vx[i] * p.vx[i] + p.vy[i] * p.vy[i] + p.vz[i] * p.vz[i]);
    d.P[0] += m * p.vx[i]; d.P[1] += m * p.vy[i]; d.P[2] += m * p.vz[i];
    d.L[0] += m * (p.y[i] * p.vz[i] - p.z[i] * p.vy[i]);
    d.L[1] += m * (p.z[i] * p.vx[i] - p.x[i] * p.vz[i]);
    d.L[2] += m * (p.x[i] * p.vy[i] - p.y[i] * p.vx[i]);
    for (size_t k = i + 1; k < n; ++k) {
      const double dx = p.x[k] - p.x[i], dy = p.y[k] - p.y[i], dz = p.z[k] - p.z[i];
      U += m * p.m[k] / std::sqrt(dx * dx + dy * dy + dz * dz + eps2);
    }
  }
  d.U = -G * U;
  d.E = d.K + d.U;
  return d;
}
}  // namespace ref

// Physics scenarios, templated over the integrator: make(p, c) -> unique_ptr<X>, where X has
// advance_to(double), state(), levels(), status(). They run on ref::Ref (CPU) and on h4nb::Simulation (GPU).
// The limits come from a model of this algorithm (plan: "Measured numbers"). Do not make them looser without the user.
#pragma once
#include <algorithm>
#include <cmath>
#include <cstdio>
#include "check.hpp"
#include "kepler.hpp"
#include "reference.hpp"

constexpr double kPi = 3.14159265358979323846;

struct TwoBody {
  h4nb::Particles p;
  double mu;
};

// m0 = 1, m1 at semi-major axis 1, start at pericentre. Barycentric unless fixed_center (then m0 sits at the origin).
inline TwoBody two_body(double e, double m1, bool fixed_center) {
  TwoBody tb;
  tb.mu = fixed_center ? 1.0 : 1.0 + m1;
  double r[3], v[3];
  kepler_rel(tb.mu, 1.0, e, 0.0, r, v);
  const double f0 = fixed_center ? 0.0 : -m1 / (1.0 + m1), f1 = fixed_center ? 1.0 : 1.0 / (1.0 + m1);
  tb.p.id = {0, 1};
  tb.p.m = {1.0, m1};
  tb.p.x = {f0 * r[0], f1 * r[0]}; tb.p.y = {f0 * r[1], f1 * r[1]}; tb.p.z = {0.0, 0.0};
  tb.p.vx = {f0 * v[0], f1 * v[0]}; tb.p.vy = {f0 * v[1], f1 * v[1]}; tb.p.vz = {0.0, 0.0};
  return tb;
}

inline double rel_error(const h4nb::Particles& s, const double r[3]) {
  return std::sqrt(std::pow(s.x[1] - s.x[0] - r[0], 2) + std::pow(s.y[1] - s.y[0] - r[1], 2) +
                   std::pow(s.z[1] - s.z[0] - r[2], 2));
}

// TZ 11.1: one orbit with block steps; energy, angular momentum, position vs analytic.
template <class Make>
void kepler_orbit(Make make, double e, bool fixed_center) {
  const TwoBody tb = two_body(e, 1e-3, fixed_center);
  h4nb::Config c;
  c.eta = 0.0005;
  c.dt_max = 1.0 / 16;
  c.max_level = 30;
  c.fixed_center = fixed_center;
  auto sim = make(tb.p, c);
  const h4nb::Diagnostics d0 = ref::direct_diagnostics(sim->state(), c.G, c.eps2);
  const int n = int(2 * kPi / std::sqrt(tb.mu) / c.dt_max);
  double dE = 0, dL = 0;
  for (int k = 1; k <= n; ++k) {
    sim->advance_to(k * c.dt_max);
    const h4nb::Diagnostics d = ref::direct_diagnostics(sim->state(), c.G, c.eps2);
    dE = std::max(dE, std::fabs((d.E - d0.E) / d0.E));
    dL = std::max(dL, std::fabs((d.L[2] - d0.L[2]) / d0.L[2]));
  }
  double r[3], v[3];
  kepler_rel(tb.mu, 1.0, e, n * c.dt_max, r, v);
  const double err = rel_error(sim->state(), r);
  std::printf("kepler e=%.1f fixed_center=%d: dE_max=%.2e dL_max=%.2e pos_err=%.2e\n", e, int(fixed_center), dE, dL, err);
  CHECK(dE <= 1e-8);
  CHECK(dL <= 2e-8);
  CHECK(err <= 1e-6);
  CHECK(sim->status() == 0);
}

// TZ 11.6: Fixed shared step h, h/2, h/4, h/8 -> error ratio ~16.
template <class Make>
void convergence(Make make, double e) {
  double err[4];
  for (int k = 0; k < 4; ++k) {
    const TwoBody tb = two_body(e, 1e-3, false);
    h4nb::Config c;
    c.mode = h4nb::StepMode::Fixed;
    c.dt_max = 1.0 / 8;
    c.max_level = 30;
    c.fixed_level = 3 + k;
    auto sim = make(tb.p, c);
    sim->advance_to(1.0);
    double r[3], v[3];
    kepler_rel(tb.mu, 1.0, e, 1.0, r, v);
    err[k] = rel_error(sim->state(), r);
  }
  for (int k = 0; k < 3; ++k) {
    const double ratio = err[k] / err[k + 1];
    std::printf("convergence e=%.1f: e(h)=%.2e ratio=%.2f\n", e, err[k], ratio);
    CHECK(ratio > 14.0 && ratio < 18.0);
  }
}

// Inner binary (1, 0.3) at separation 1, third body 0.1 at distance 10; centre-of-mass frame.
inline h4nb::Particles hierarchical_triple() {
  h4nb::Particles p;
  const double mb = 1.3, vb = std::sqrt(mb);
  p.id = {0, 1, 2};
  p.m = {1.0, 0.3, 0.1};
  p.x = {-0.3 / mb, 1.0 / mb, 10.0}; p.y = {0, 0, 0}; p.z = {0, 0, 0};
  p.vx = {0, 0, 0}; p.vy = {-0.3 / mb * vb, 1.0 / mb * vb, std::sqrt(1.4 / 10.0)}; p.vz = {0, 0, 0};
  double M = 0, cx = 0, cvy = 0;
  for (int i = 0; i < 3; ++i) { M += p.m[i]; cx += p.m[i] * p.x[i]; cvy += p.m[i] * p.vy[i]; }
  for (int i = 0; i < 3; ++i) { p.x[i] -= cx / M; p.vy[i] -= cvy / M; }
  return p;
}

// TZ 11.2: mutual gravity, a moving central body, conservation of P (exact for a shared step) and E.
template <class Make>
void triple(Make make, bool fixed) {
  const h4nb::Particles p0 = hierarchical_triple();
  h4nb::Config c;
  c.dt_max = 1.0 / 16;
  c.max_level = 30;
  c.eta = 0.001;
  if (fixed) {
    c.mode = h4nb::StepMode::Fixed;
    c.fixed_level = 7;
  }
  auto sim = make(p0, c);
  const h4nb::Diagnostics d0 = ref::direct_diagnostics(sim->state(), c.G, c.eps2);
  double pscale = 0;
  for (size_t i = 0; i < p0.size(); ++i) pscale += p0.m[i] * std::hypot(p0.vx[i], p0.vy[i], p0.vz[i]);
  double dE = 0, dP = 0;
  for (int k = 1; k <= 160; ++k) {
    sim->advance_to(k / 16.0);
    const h4nb::Diagnostics d = ref::direct_diagnostics(sim->state(), c.G, c.eps2);
    dE = std::max(dE, std::fabs((d.E - d0.E) / d0.E));
    dP = std::max(dP, std::hypot(d.P[0] - d0.P[0], d.P[1] - d0.P[1], d.P[2] - d0.P[2]) / pscale);
  }
  std::printf("triple fixed=%d: dE_max=%.2e dP_max=%.2e\n", int(fixed), dE, dP);
  CHECK(dE <= (fixed ? 1e-12 : 1e-9));
  CHECK(dP <= (fixed ? 1e-13 : 1e-10));
  CHECK(sim->status() == 0);
}

  - `make_disk(n, disk_frac, r_in, r_out, seed) -> Particles` (n disk particles plus the central body at index 0, G = 1) and `periods(p) -> Periods{mean, median, mass_weighted}` in `tools/disk.hpp`.
  - Kernels in `src/kernels.cuh`: `BI = 128`, `predict_kernel`, `gather_kernel`, `force_kernel`, `sum_partials`, `correct_kernel`, `potential_kernel`, `sum_phi`.

**How a block step works (read this before the code):**
1. Each GPU reduces the `next` times of its own particles (CUB `DeviceReduce::Min`). The host takes the minimum of these values, `Tn`. This is host sync 1.
2. Each GPU predicts all of its own particles to `Tn`. Then it selects its active particles (`next == Tn`) with CUB `DeviceSelect::If` and sends the count to the host. This is host sync 2. The host now has the offsets `off[g]` and the total `NA`.
3. Each GPU puts the predicted state of its active particles into `tx/tv/tid[off[g] ...]`. Then it copies this slice into the same offset on every other GPU. After the copies, it records `ev_tx`.
4. Each GPU h waits for all `ev_tx` events. It runs `force_kernel` over grid `(ceil(NA/BI), nj)`: thread = one target, block row y = one chunk of h's sources, and shared memory holds one tile of BI sources. Then `sum_partials` adds the nj rows in order. GPU h copies the slice `off[g]` of its result into `ra/rj` row h of owner g, and records `ev_f`.
5. Each owner g waits for all `ev_f` events. It adds the G rows in device order (`sum_partials`), then runs `correct_kernel` → `update_particle`.

Ordering rule: the host syncs in steps 1 and 2. Because of these syncs, no copy in step k+1 overwrites a buffer that step k still reads.

#pragma once
#include <algorithm>
#include <cmath>
#include <random>
#include <vector>
#include "h4nb/h4nb.hpp"

// Central body (m = 1, index 0) plus n disk particles of total mass disk_frac. G = 1.
// Radius uniform in [r_in, r_out] (surface density ~ 1/r), thin (h = 0.01 r), near-circular orbits
// with the enclosed mass. Output is in the centre-of-mass frame. TZ 11.3: "approximately Keplerian".
inline h4nb::Particles make_disk(int n, double disk_frac, double r_in, double r_out, uint64_t seed) {
  constexpr double kTwoPi = 6.28318530717958647692;
  h4nb::Particles p;
  p.resize(size_t(n) + 1);
  std::mt19937_64 rng(seed);
  std::uniform_real_distribution<double> u(0.0, 1.0);
  std::normal_distribution<double> g(0.0, 1.0);
  p.id[0] = 0;
  p.m[0] = 1.0;
  for (int k = 1; k <= n; ++k) {
    const double r = r_in + (r_out - r_in) * u(rng), phi = kTwoPi * u(rng);
    const double vc = std::sqrt((1.0 + disk_frac * (r - r_in) / (r_out - r_in)) / r);
    p.id[k] = k;
    p.m[k] = disk_frac / n;
    p.x[k] = r * std::cos(phi); p.y[k] = r * std::sin(phi); p.z[k] = 0.01 * r * g(rng);
    p.vx[k] = -vc * std::sin(phi); p.vy[k] = vc * std::cos(phi); p.vz[k] = 0.0;
  }
  double M = 0, c[6] = {0, 0, 0, 0, 0, 0};
  for (size_t i = 0; i < p.size(); ++i) {
    M += p.m[i];
    c[0] += p.m[i] * p.x[i]; c[1] += p.m[i] * p.y[i]; c[2] += p.m[i] * p.z[i];
    c[3] += p.m[i] * p.vx[i]; c[4] += p.m[i] * p.vy[i]; c[5] += p.m[i] * p.vz[i];
  }
  for (size_t i = 0; i < p.size(); ++i) {
    p.x[i] -= c[0] / M; p.y[i] -= c[1] / M; p.z[i] -= c[2] / M;
    p.vx[i] -= c[3] / M; p.vy[i] -= c[4] / M; p.vz[i] -= c[5] / M;
  }
  return p;
}

struct Periods { double mean = 0, median = 0, mass_weighted = 0; };

// Keplerian period of each bound particle around body 0 (TZ 6.3). Only an estimate when the disk is heavy.
inline Periods periods(const h4nb::Particles& p) {
  constexpr double kTwoPi = 6.28318530717958647692;
  std::vector<double> P;
  double wsum = 0, msum = 0;
  for (size_t i = 1; i < p.size(); ++i) {
    const double dx = p.x[i] - p.x[0], dy = p.y[i] - p.y[0], dz = p.z[i] - p.z[0];
    const double dvx = p.vx[i] - p.vx[0], dvy = p.vy[i] - p.vy[0], dvz = p.vz[i] - p.vz[0];
    const double mu = p.m[0] + p.m[i];
    const double a = 1.0 / (2.0 / std::sqrt(dx * dx + dy * dy + dz * dz) - (dvx * dvx + dvy * dvy + dvz * dvz) / mu);
    if (!(a > 0)) continue;
    const double Pi = kTwoPi * std::sqrt(a * a * a / mu);
    P.push_back(Pi);
    wsum += p.m[i] * Pi;
    msum += p.m[i];
  }
  Periods r;
  if (P.empty()) return r;
  double s = 0;
  for (double x : P) s += x;
  std::sort(P.begin(), P.end());
  r.mean = s / double(P.size());
  r.median = P[P.size() / 2];
  r.mass_weighted = wsum / msum;
  return r;
}

static double max_diff(const h4nb::Particles& a, const h4nb::Particles& b) {
  double d = 0;
  for (size_t i = 0; i < a.size(); ++i) {
    d = std::max({d, std::fabs(a.x[i] - b.x[i]), std::fabs(a.y[i] - b.y[i]), std::fabs(a.z[i] - b.z[i]),
                  std::fabs(a.vx[i] - b.vx[i]), std::fabs(a.vy[i] - b.vy[i]), std::fabs(a.vz[i] - b.vz[i])});
  }
  return d;
}

#include "kernels.cuh"

namespace h4nb {

__global__ void predict_kernel(int n, const d4* __restrict__ x, const d4* __restrict__ v, const d4* __restrict__ a,
                               const d4* __restrict__ j, const int64_t* __restrict__ t, int64_t T, double tick,
                               d4* __restrict__ xp, d4* __restrict__ vp) {
  const int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i >= n) return;
  predict(x[i], v[i], a[i], j[i], double(T - t[i]) * tick, xp[i], vp[i]);
}

__global__ void gather_kernel(int na, const int* __restrict__ act, const d4* __restrict__ xp,
                              const d4* __restrict__ vp, int base, d4* __restrict__ tx, d4* __restrict__ tv,
                              int* __restrict__ tid) {
  const int k = blockIdx.x * blockDim.x + threadIdx.x;
  if (k >= na) return;
  const int i = act[k];
  tx[k] = xp[i];
  tv[k] = vp[i];
  tid[k] = base + i;
}

__global__ void force_kernel(int na, const d4* __restrict__ tx, const d4* __restrict__ tv,
                             const int* __restrict__ tid, int ns, const d4* __restrict__ sx,
                             const d4* __restrict__ sv, int sbase, int chunk, double eps2, d4* __restrict__ pa,
                             d4* __restrict__ pj) {
  __shared__ d4 shx[BI], shv[BI];
  const int i = blockIdx.x * BI + threadIdx.x;
  const int j0 = blockIdx.y * chunk, j1 = min(ns, j0 + chunk);
  d4 xi{0, 0, 0, 0}, vi{0, 0, 0, 0};
  int gi = -1;
  if (i < na) {
    xi = tx[i];
    vi = tv[i];
    gi = tid[i];
  }
  AJ f;
  for (int t0 = j0; t0 < j1; t0 += BI) {
    const int js = t0 + threadIdx.x;
    if (js < j1) {
      shx[threadIdx.x] = sx[js];
      shv[threadIdx.x] = sv[js];
    }
    __syncthreads();
    const int nt = min(BI, j1 - t0);
#pragma unroll 4
    for (int k = 0; k < nt; ++k)
      if (sbase + t0 + k != gi) accumulate(f, xi, vi, shx[k], shv[k], eps2);
    __syncthreads();
  }
  if (i < na) {
    const size_t o = size_t(blockIdx.y) * na + i;
    pa[o] = d4{f.ax, f.ay, f.az, f.r2min};
    pj[o] = d4{f.jx, f.jy, f.jz, 0.0};
  }
}

__global__ void sum_partials(int na, int nparts, const d4* __restrict__ pa, const d4* __restrict__ pj,
                             d4* __restrict__ fa, d4* __restrict__ fj) {
  const int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i >= na) return;
  d4 a = pa[i], j = pj[i];
  for (int y = 1; y < nparts; ++y) {
    const d4 b = pa[size_t(y) * na + i], c = pj[size_t(y) * na + i];
    a.x += b.x; a.y += b.y; a.z += b.z; a.w = fmin(a.w, b.w);
    j.x += c.x; j.y += c.y; j.z += c.z;
  }
  fa[i] = a;
  fj[i] = j;
}

__global__ void correct_kernel(int na, const int* __restrict__ act, const d4* __restrict__ fa,
                               const d4* __restrict__ fj, StepParams p, int center, d4* x, d4* v, d4* a, d4* j,
                               int64_t* t, int64_t* next, int* level, unsigned* status) {
  const int k = blockIdx.x * blockDim.x + threadIdx.x;
  if (k >= na) return;
  const int i = act[k];
  const d4 f = fa[k], g = fj[k];
  const d4 a1{p.G * f.x, p.G * f.y, p.G * f.z, 0.0};
  const d4 j1{p.G * g.x, p.G * g.y, p.G * g.z, 0.0};
  d4 xi = x[i], vi = v[i], ai = a[i], ji = j[i];
  int64_t ti = t[i], ni = 0;
  int li = level[i];
  const unsigned st = update_particle(p, i == center, a1, j1, f.w, xi, vi, ai, ji, ti, ni, li);
  x[i] = xi; v[i] = vi; a[i] = ai; j[i] = ji;
  t[i] = ti; next[i] = ni; level[i] = li;
  if (st) atomicOr(status, st);
}

__global__ void potential_kernel(int n, const d4* __restrict__ xall, int ns, int sbase, int chunk, double eps2,
                                 double* __restrict__ pphi) {
  __shared__ d4 shx[BI];
  const int i = blockIdx.x * BI + threadIdx.x;
  const int j0 = blockIdx.y * chunk, j1 = min(ns, j0 + chunk);
  double phi = 0;
  if (sbase + j1 - 1 > int(blockIdx.x) * BI) {  // the block has at least one pair j > i (same for the whole block)
    const d4 xi = i < n ? xall[i] : d4{0, 0, 0, 0};
    for (int t0 = j0; t0 < j1; t0 += BI) {
      const int js = t0 + threadIdx.x;
      if (js < j1) shx[threadIdx.x] = xall[sbase + js];
      __syncthreads();
      const int nt = min(BI, j1 - t0);
      for (int k = 0; k < nt; ++k) {
        if (sbase + t0 + k > i) {
          const double dx = shx[k].x - xi.x, dy = shx[k].y - xi.y, dz = shx[k].z - xi.z;
          phi += shx[k].w * h4_rsqrt(dx * dx + dy * dy + dz * dz + eps2);
        }
      }
      __syncthreads();
    }
  }
  if (i < n) pphi[size_t(blockIdx.y) * n + i] = phi;
}

__global__ void sum_phi(int n, int nparts, const double* __restrict__ pphi, double* __restrict__ phi) {
  const int i = blockIdx.x * blockDim.x + threadIdx.x;
  if (i >= n) return;
  double s = 0;
  for (int y = 0; y < nparts; ++y) s += pphi[size_t(y) * n + i];
  phi[i] = s;
}

}  // namespace h4nb

#include <thrust/iterator/counting_iterator.h>

namespace h4nb {
namespace {

void ck(cudaError_t e, const char* what) {
  if (e != cudaSuccess) throw std::runtime_error(std::string(what) + ": " + cudaGetErrorString(e));
}
#define H4_CUDA(call) ck((call), #call)

int blocks(int n, int b) { return (n + b - 1) / b; }

struct IsActive {
  const int64_t* next;
  int64_t T;
  __device__ bool operator()(int i) const { return next[i] == T; }
};

// j-split so that a launch has about 4 blocks per SM even when few targets are active.
struct Split { int nj, chunk; };
Split split(int na, int ns, int sms) {
  const int nj = std::max(1, std::min(blocks(4 * sms, blocks(na, BI)), blocks(ns, BI)));
  const int chunk = blocks(blocks(ns, nj), BI) * BI;
  return {blocks(ns, chunk), chunk};
}

// Neumaier compensated sum (TZ 4.4, 6.1).
struct NSum {
  double s = 0, c = 0;
  void add(double x) {
    const double t = s + x;
    c += std::fabs(s) >= std::fabs(x) ? (s - t) + x : (x - t) + s;
    s = t;
  }
  double value() const { return s + c; }
};

void copy(void* dst, const void* src, size_t bytes, cudaStream_t s) {
  if (bytes) H4_CUDA(cudaMemcpyAsync(dst, src, bytes, cudaMemcpyDefault, s));
}

}  // namespace

struct Dev {
  int id = 0, base = 0, n = 0, sms = 0;  // owns global particles [base, base + n)
  cudaStream_t s{};
  cudaEvent_t ev_tx{}, ev_f{};
  d4 *x, *v, *a, *j, *xp, *vp;           // owned state and predicted sources
  int64_t *t, *next, *dmin;
  int *level, *act, *nsel;
  unsigned* status;
  d4 *tx, *tv;                           // all active targets (size N), or all positions in diagnostics
  int* tid;
  d4 *pa, *pj;                           // j-split partials, capacity pcap
  size_t pcap = 0;
  d4 *fa, *fj;                           // this device's force on all targets (size N)
  d4 *ra, *rj;                           // partials received from each device for own targets (G * n)
  d4 *ca, *cj;                           // summed force on own targets (n)
  double* phi;                           // potential sums (N)
  void* tmp = nullptr;
  size_t tmp_bytes = 0;
  int64_t* h_min = nullptr;              // pinned
  int* h_nsel = nullptr;                 // pinned
  std::vector<void*> mem;

  template <class T>
  T* alloc(size_t count) {
    void* p = nullptr;
    H4_CUDA(cudaMalloc(&p, std::max<size_t>(count, 1) * sizeof(T)));
    mem.push_back(p);
    return static_cast<T*>(p);
  }
};

struct Simulation::Impl {
  Config c;
  int N = 0;
  double tick = 0;
  int64_t T = 0;
  std::vector<int64_t> ids;
  std::vector<Dev> d;
  Stats st;

  static void use(const Dev& e) { H4_CUDA(cudaSetDevice(e.id)); }
  void sync() {
    for (auto& e : d) {
      use(e);
      H4_CUDA(cudaStreamSynchronize(e.s));
    }
  }

  Impl(const Particles& p, const Config& cfg) : c(cfg), N(int(p.size())) {
    const int G = int(c.devices.size());
    const size_t n = p.size();
    if (G < 1) throw std::invalid_argument("Config::devices is empty");
    if (N < std::max(2, G)) throw std::invalid_argument("need at least max(2, devices) particles");
    if (p.id.size() != n || p.x.size() != n || p.y.size() != n || p.z.size() != n || p.vx.size() != n ||
        p.vy.size() != n || p.vz.size() != n)
      throw std::invalid_argument("Particles arrays differ in size");
    if (c.max_level < 0 || c.max_level > 50) throw std::invalid_argument("max_level must be in [0, 50]");
    if (c.mode == StepMode::Fixed && (c.fixed_level < 0 || c.fixed_level > c.max_level))
      throw std::invalid_argument("fixed_level must be in [0, max_level]");
    if (!(c.dt_max > 0) || !(c.eta > 0) || !(c.eta_init > 0)) throw std::invalid_argument("dt_max, eta, eta_init must be > 0");
    tick = c.dt_max / std::ldexp(1.0, c.max_level);
    ids = p.id;
    d.resize(size_t(G));
    for (int g = 0; g < G; ++g) {
      Dev& e = d[size_t(g)];
      e.id = c.devices[size_t(g)];
      e.base = int(int64_t(N) * g / G);
      e.n = int(int64_t(N) * (g + 1) / G) - e.base;
      use(e);
      H4_CUDA(cudaDeviceGetAttribute(&e.sms, cudaDevAttrMultiProcessorCount, e.id));
      H4_CUDA(cudaStreamCreate(&e.s));
      H4_CUDA(cudaEventCreateWithFlags(&e.ev_tx, cudaEventDisableTiming));
      H4_CUDA(cudaEventCreateWithFlags(&e.ev_f, cudaEventDisableTiming));
      const size_t nn = size_t(e.n), NN = size_t(N);
      e.x = e.alloc<d4>(nn); e.v = e.alloc<d4>(nn); e.a = e.alloc<d4>(nn); e.j = e.alloc<d4>(nn);
      e.xp = e.alloc<d4>(nn); e.vp = e.alloc<d4>(nn);
      e.t = e.alloc<int64_t>(nn); e.next = e.alloc<int64_t>(nn); e.dmin = e.alloc<int64_t>(1);
      e.level = e.alloc<int>(nn); e.act = e.alloc<int>(nn); e.nsel = e.alloc<int>(1);
      e.status = e.alloc<unsigned>(1);
      e.tx = e.alloc<d4>(NN); e.tv = e.alloc<d4>(NN); e.tid = e.alloc<int>(NN);
      e.pcap = NN + size_t(4) * size_t(e.sms) * BI;  // >= na * nj for every split (see split())
      e.pa = e.alloc<d4>(e.pcap); e.pj = e.alloc<d4>(e.pcap);
      e.fa = e.alloc<d4>(NN); e.fj = e.alloc<d4>(NN);
      e.ra = e.alloc<d4>(size_t(G) * nn); e.rj = e.alloc<d4>(size_t(G) * nn);
      e.ca = e.alloc<d4>(nn); e.cj = e.alloc<d4>(nn);

      H4_CUDA(cub::DeviceReduce::Min(nullptr, b1, e.next, e.dmin, e.n));
      H4_CUDA(cub::DeviceSelect::If(nullptr, b2, thrust::counting_iterator<int>(0), e.act, e.nsel, e.n,
                                    IsActive{e.next, 0}));
      e.tmp_bytes = std::max(b1, b2);
      e.tmp = e.alloc<char>(e.tmp_bytes);
      H4_CUDA(cudaMallocHost(&e.h_min, sizeof(int64_t)));
      H4_CUDA(cudaMallocHost(&e.h_nsel, sizeof(int)));
      std::vector<d4> hx(nn), hv(nn);
      for (int k = 0; k < e.n; ++k) {
        const size_t i = size_t(e.base + k);
        hx[size_t(k)] = d4{p.x[i], p.y[i], p.z[i], p.m[i]};
        hv[size_t(k)] = d4{p.vx[i], p.vy[i], p.vz[i], 0.0};
      }
      if (c.fixed_center && g == 0) hv[0] = d4{0, 0, 0, 0};
      H4_CUDA(cudaMemcpy(e.x, hx.data(), nn * sizeof(d4), cudaMemcpyHostToDevice));
      H4_CUDA(cudaMemcpy(e.v, hv.data(), nn * sizeof(d4), cudaMemcpyHostToDevice));
      H4_CUDA(cudaMemset(e.a, 0, nn * sizeof(d4)));
      H4_CUDA(cudaMemset(e.j, 0, nn * sizeof(d4)));
      H4_CUDA(cudaMemset(e.t, 0, nn * sizeof(int64_t)));
      H4_CUDA(cudaMemset(e.next, 0, nn * sizeof(int64_t)));
      H4_CUDA(cudaMemset(e.level, 0, nn * sizeof(int)));
      H4_CUDA(cudaMemset(e.status, 0, sizeof(unsigned)));
    }
    std::set<std::pair<int, int>> done;  // best-effort peer access between distinct devices
    for (auto& a : d)
      for (auto& b : d)
        if (a.id != b.id && done.insert({a.id, b.id}).second) {
          int ok = 0;
          H4_CUDA(cudaDeviceCanAccessPeer(&ok, a.id, b.id));
          if (!ok) continue;
          use(a);
          const cudaError_t r = cudaDeviceEnablePeerAccess(b.id, 0);
          if (r != cudaSuccess && r != cudaErrorPeerAccessAlreadyEnabled) ck(r, "cudaDeviceEnablePeerAccess");
          (void)cudaGetLastError();
        }
    step(true);
    sync();
  }

  ~Impl() {
    for (auto& e : d) {
      cudaSetDevice(e.id);
      cudaStreamSynchronize(e.s);
      for (void* m : e.mem) cudaFree(m);
      cudaFreeHost(e.h_min);
      cudaFreeHost(e.h_nsel);
      cudaEventDestroy(e.ev_tx);
      cudaEventDestroy(e.ev_f);
      cudaStreamDestroy(e.s);
    }
  }

  // One block step (see "How a block step works" in the plan).
  // ponytail: 2 host syncs per block step (~10-30 us); matters only when NA is tiny. Upgrade: CUDA graphs / device-side scheduling (O4).
  void step(bool init) {
    const int G = int(d.size());
    int64_t Tn = 0;
    if (!init) {
      for (auto& e : d) {
        use(e);
        H4_CUDA(cub::DeviceReduce::Min(e.tmp, e.tmp_bytes, e.next, e.dmin, e.n, e.s));
        H4_CUDA(cudaMemcpyAsync(e.h_min, e.dmin, sizeof(int64_t), cudaMemcpyDeviceToHost, e.s));
      }
      Tn = INT64_MAX;
      for (auto& e : d) {
        use(e);
        H4_CUDA(cudaStreamSynchronize(e.s));
        Tn = std::min(Tn, *e.h_min);
      }
    }
    for (auto& e : d) {
      use(e);
      predict_kernel<<<blocks(e.n, 256), 256, 0, e.s>>>(e.n, e.x, e.v, e.a, e.j, e.t, Tn, tick, e.xp, e.vp);
      size_t bytes = e.tmp_bytes;
      H4_CUDA(cub::DeviceSelect::If(e.tmp, bytes, thrust::counting_iterator<int>(0), e.act, e.nsel, e.n,
                                    IsActive{e.next, Tn}, e.s));
      H4_CUDA(cudaMemcpyAsync(e.h_nsel, e.nsel, sizeof(int), cudaMemcpyDeviceToHost, e.s));
    }
    std::vector<int> off(size_t(G)), na(size_t(G));
    int NA = 0;
    for (int g = 0; g < G; ++g) {
      use(d[size_t(g)]);
      H4_CUDA(cudaStreamSynchronize(d[size_t(g)].s));
      na[size_t(g)] = *d[size_t(g)].h_nsel;
      off[size_t(g)] = NA;
      NA += na[size_t(g)];
    }
    // All-gather the active targets.
    for (int g = 0; g < G; ++g) {
      Dev& e = d[size_t(g)];
      const int o = off[size_t(g)], m = na[size_t(g)];
      use(e);
      if (m) gather_kernel<<<blocks(m, 256), 256, 0, e.s>>>(m, e.act, e.xp, e.vp, e.base, e.tx + o, e.tv + o, e.tid + o);
      for (int h = 0; h < G; ++h) {
        if (h == g) continue;
        copy(d[size_t(h)].tx + o, e.tx + o, size_t(m) * sizeof(d4), e.s);
        copy(d[size_t(h)].tv + o, e.tv + o, size_t(m) * sizeof(d4), e.s);
        copy(d[size_t(h)].tid + o, e.tid + o, size_t(m) * sizeof(int), e.s);
      }
      H4_CUDA(cudaEventRecord(e.ev_tx, e.s));
    }
    // Partial forces of each device's sources on all targets, then scatter the slices to their owners.
    for (int h = 0; h < G; ++h) {
      Dev& e = d[size_t(h)];
      use(e);
      for (int g = 0; g < G; ++g)
        if (g != h) H4_CUDA(cudaStreamWaitEvent(e.s, d[size_t(g)].ev_tx, 0));
      const Split sp = split(NA, e.n, e.sms);
      force_kernel<<<dim3(unsigned(blocks(NA, BI)), unsigned(sp.nj)), BI, 0, e.s>>>(
          NA, e.tx, e.tv, e.tid, e.n, e.xp, e.vp, e.base, sp.chunk, c.eps2, e.pa, e.pj);
      sum_partials<<<blocks(NA, 256), 256, 0, e.s>>>(NA, sp.nj, e.pa, e.pj, e.fa, e.fj);
      for (int g = 0; g < G; ++g) {
        const size_t m = size_t(na[size_t(g)]), row = size_t(h) * m;
        copy(d[size_t(g)].ra + row, e.fa + off[size_t(g)], m * sizeof(d4), e.s);
        copy(d[size_t(g)].rj + row, e.fj + off[size_t(g)], m * sizeof(d4), e.s);
      }
      H4_CUDA(cudaEventRecord(e.ev_f, e.s));
    }
    // Owners add the rows in device order and correct.
    const StepParams sp = make_params(c, tick, Tn, init);
    for (int g = 0; g < G; ++g) {
      Dev& e = d[size_t(g)];
      const int m = na[size_t(g)];
      use(e);
      for (int h = 0; h < G; ++h)
        if (h != g) H4_CUDA(cudaStreamWaitEvent(e.s, d[size_t(h)].ev_f, 0));
      if (!m) continue;
      sum_partials<<<blocks(m, 256), 256, 0, e.s>>>(m, G, e.ra, e.rj, e.ca, e.cj);
      correct_kernel<<<blocks(m, 256), 256, 0, e.s>>>(m, e.act, e.ca, e.cj, sp, (c.fixed_center && g == 0) ? 0 : -1,
                                                       e.x, e.v, e.a, e.j, e.t, e.next, e.level, e.status);
    }
    H4_CUDA(cudaGetLastError());
    T = Tn;
    ++st.block_steps;
    st.active_total += NA;
  }
};

Simulation::Simulation(const Particles& p, const Config& c) : impl_(std::make_unique<Impl>(p, c)) {}
Simulation::~Simulation() = default;

void Simulation::advance_to(double t) {
  Impl& m = *impl_;
  const double q = t / m.c.dt_max, r = std::nearbyint(q);
  if (std::fabs(q - r) > 1e-9 * std::max(1.0, std::fabs(q)))
    throw std::invalid_argument("advance_to: t must be a multiple of dt_max");
  if (r < 0 || r >= std::ldexp(1.0, 62 - m.c.max_level)) throw std::invalid_argument("advance_to: t out of range");
  const int64_t target = int64_t(r) << m.c.max_level;
  if (target < m.T) throw std::invalid_argument("advance_to: t is before time()");
  while (m.T < target) m.step(false);
  m.sync();
}

double Simulation::time() const { return double(impl_->T) * impl_->tick; }
Stats Simulation::stats() const { return impl_->st; }

Particles Simulation::state() const {
  Impl& m = *impl_;
  m.sync();
  Particles p;
  p.resize(size_t(m.N));
  p.id = m.ids;
  std::vector<d4> hx, hv;
  for (auto& e : m.d) {
    Impl::use(e);
    hx.resize(size_t(e.n));
    hv.resize(size_t(e.n));
    H4_CUDA(cudaMemcpy(hx.data(), e.x, hx.size() * sizeof(d4), cudaMemcpyDeviceToHost));
    H4_CUDA(cudaMemcpy(hv.data(), e.v, hv.size() * sizeof(d4), cudaMemcpyDeviceToHost));
    for (int k = 0; k < e.n; ++k) {
      const size_t i = size_t(e.base + k);
      const d4 &x = hx[size_t(k)], &v = hv[size_t(k)];
      p.m[i] = x.w; p.x[i] = x.x; p.y[i] = x.y; p.z[i] = x.z;
      p.vx[i] = v.x; p.vy[i] = v.y; p.vz[i] = v.z;
    }
  }
  return p;
}

std::vector<int> Simulation::levels() const {
  Impl& m = *impl_;
  m.sync();
  std::vector<int> out(size_t(m.N));
  for (auto& e : m.d) {
    Impl::use(e);
    H4_CUDA(cudaMemcpy(out.data() + e.base, e.level, size_t(e.n) * sizeof(int), cudaMemcpyDeviceToHost));
  }
  return out;
}

unsigned Simulation::status() const {
  Impl& m = *impl_;
  m.sync();
  unsigned s = 0;
  for (auto& e : m.d) {
    Impl::use(e);
    unsigned v = 0;
    H4_CUDA(cudaMemcpy(&v, e.status, sizeof v, cudaMemcpyDeviceToHost));
    s |= v;
  }
  return s;
}

// Diagnostics at a sync point (all particles have t = T), so the state is exact, not predicted (D6).
// The potential is computed on the GPU over unique pairs j > i. K, P, L and all final sums are on the host,
// in a fixed order with Neumaier summation.
// ponytail: downloads N doubles per device plus the state; fine at a diagnostic cadence. Upgrade: GPU tree reduction.
Diagnostics Simulation::diagnostics() {
  Impl& m = *impl_;
  const Particles p = state();
  const int G = int(m.d.size());
  for (auto& e : m.d) {  // all-gather every position into tx (global order)
    Impl::use(e);
    for (auto& f : m.d) copy(f.tx + e.base, e.x, size_t(e.n) * sizeof(d4), e.s);
    H4_CUDA(cudaEventRecord(e.ev_tx, e.s));
  }
  std::vector<std::vector<double>> ph(size_t(G), std::vector<double>(size_t(m.N)));
  for (int h = 0; h < G; ++h) {
    Dev& e = m.d[size_t(h)];
    Impl::use(e);
    for (int g = 0; g < G; ++g)
      if (g != h) H4_CUDA(cudaStreamWaitEvent(e.s, m.d[size_t(g)].ev_tx, 0));
    const Split sp = split(m.N, e.n, e.sms);
    double* pp = reinterpret_cast<double*>(e.pa);  // N * nj doubles fit in pcap d4
    potential_kernel<<<dim3(unsigned(blocks(m.N, BI)), unsigned(sp.nj)), BI, 0, e.s>>>(m.N, e.tx, e.n, e.base,
                                                                                        sp.chunk, m.c.eps2, pp);
    sum_phi<<<blocks(m.N, 256), 256, 0, e.s>>>(m.N, sp.nj, pp, e.phi);
    H4_CUDA(cudaMemcpyAsync(ph[size_t(h)].data(), e.phi, size_t(m.N) * sizeof(double), cudaMemcpyDeviceToHost, e.s));
  }
  m.sync();
  H4_CUDA(cudaGetLastError());
  NSum K, U, P[3], L[3];
  for (size_t i = 0; i < p.size(); ++i) {
    double phi = 0;
    for (int h = 0; h < G; ++h) phi += ph[size_t(h)][i];
    const double mi = p.m[i];
    U.add(mi * phi);
    K.add(0.5 * mi * (p.vx[i] * p.vx[i] + p.vy[i] * p.vy[i] + p.vz[i] * p.vz[i]));
    P[0].add(mi * p.vx[i]); P[1].add(mi * p.vy[i]); P[2].add(mi * p.vz[i]);
    L[0].add(mi * (p.y[i] * p.vz[i] - p.z[i] * p.vy[i]));
    L[1].add(mi * (p.z[i] * p.vx[i] - p.x[i] * p.vz[i]));
    L[2].add(mi * (p.x[i] * p.vy[i] - p.y[i] * p.vx[i]));
  }
  Diagnostics r;
  r.time = time();
  r.K = K.value();
  r.U = -m.c.G * U.value();
  r.E = r.K + r.U;
  for (int k = 0; k < 3; ++k) {
    r.P[k] = P[k].value();
    r.L[k] = L[k].value();
  }
  return r;
}

// key=value command-line arguments.
struct Args {
  std::map<std::string, std::string> kv;
  Args(int argc, char** argv) {
    for (int i = 1; i < argc; ++i) {
      const std::string s = argv[i];
      const size_t e = s.find('=');
      if (e == std::string::npos) throw std::invalid_argument("expected key=value, got '" + s + "'");

    }
  }
  bool has(const std::string& k) const { return kv.count(k) != 0; }
  std::string str(const std::string& k, const std::string& def = "") const { return has(k) ? kv.at(k) : def; }
  double num(const std::string& k, double def) const { return has(k) ? std::stod(kv.at(k)) : def; }
  std::vector<int> ints(const std::string& k, const std::string& def) const {
    std::vector<int> out;
    std::stringstream ss(str(k, def));
    for (std::string t; std::getline(ss, t, ',');) out.push_back(std::stoi(t));
    return out;

`tools/h4nb_run.cpp`:

```cpp
// h4nb_run: runs a simulation and writes energy/momentum/timesteps/performance .dat files and snapshots.
// Usage: h4nb_run ic=<file.txt|file.snap> out=<dir> t_end=<t> [diag=<dt>] [snap=<dt>] [eta=0.01] [eta_init=0.01]
//        [dt_max=0.015625] [max_level=40] [eps=0] [mode=block|fixed] [fixed_level=0] [fixed_center=0]
//        [r_close=0] [devices=0,1]
// t_end, diag, snap must be multiples of dt_max (and t_end, snap of diag).
#include <algorithm>
#include <chrono>
#include <cmath>
#include <cstdio>
#include <filesystem>
#include <string>
#include "args.hpp"
#include "h4nb/h4nb.hpp"

using Clock = std::chrono::steady_clock;
static double since(Clock::time_point t) { return std::chrono::duration<double>(Clock::now() - t).count(); }

int main(int argc, char** argv) try {
  const Args a(argc, argv);
  if (!a.has("ic") || !a.has("out") || !a.has("t_end")) {
    std::fprintf(stderr, "usage: h4nb_run ic=<file> out=<dir> t_end=<t> [diag= snap= eta= dt_max= devices= ...]\n");
    return 1;
  }
  h4nb::Config c;
  c.eta = a.num("eta", c.eta);
  c.eta_init = a.num("eta_init", c.eta_init);
  c.dt_max = a.num("dt_max", c.dt_max);
  c.max_level = int(a.num("max_level", c.max_level));
  c.eps2 = std::pow(a.num("eps", 0.0), 2);
  c.mode = a.str("mode", "block") == "fixed" ? h4nb::StepMode::Fixed : h4nb::StepMode::Block;
  c.fixed_level = int(a.num("fixed_level", 0));
  c.fixed_center = a.num("fixed_center", 0) != 0;
  c.r2_close = std::pow(a.num("r_close", 0.0), 2);
  c.devices = a.ints("devices", "0");
  const std::string ic = a.str("ic"), out = a.str("out");
  const double t_end = a.num("t_end", 0), diag = a.num("diag", c.dt_max), snap = a.num("snap", 0);
  const bool binary = ic.size() > 5 && ic.compare(ic.size() - 5, 5, ".snap") == 0;
  const h4nb::Particles p = binary ? h4nb::read_snapshot(ic) : h4nb::load_text(ic);
  const double N = double(p.size());
  std::filesystem::create_directories(out);
  FILE* fe = std::fopen((out + "/energy.dat").c_str(), "w");
  FILE* fm = std::fopen((out + "/momentum.dat").c_str(), "w");
  FILE* ft = std::fopen((out + "/timesteps.dat").c_str(), "w");
  FILE* fp = std::fopen((out + "/performance.dat").c_str(), "w");
  if (!fe || !fm || !ft || !fp) throw std::runtime_error("cannot write into " + out);
  std::fprintf(fe, "# time K U E rel_err max_rel_err\n");
  std::fprintf(fm, "# time Px Py Pz Lx Ly Lz\n");
  std::fprintf(ft, "# time dt_min dt_max dt_mean mean_active_per_block_step\n");
  std::fprintf(fp, "# time wall_s block_steps active pairs_per_s\n");

  const auto t0 = Clock::now();
  h4nb::Simulation sim(p, c);
  const double t_init = since(t0);
  std::printf("N=%zu devices=%zu: init (one full force pass) %.3f s, %.3e pairs/s\n", p.size(), c.devices.size(),
              t_init, N * (N - 1) / t_init);
  const h4nb::Diagnostics d0 = sim.diagnostics();
  double max_err = 0;
  auto write_diag = [&](const h4nb::Diagnostics& d) {
    const double err = std::fabs((d.E - d0.E) / d0.E);
    max_err = std::max(max_err, err);
    std::fprintf(fe, "%.17g %.17g %.17g %.17g %.6e %.6e\n", d.time, d.K, d.U, d.E, err, max_err);
    std::fprintf(fm, "%.17g %.17g %.17g %.17g %.17g %.17g %.17g\n", d.time, d.P[0], d.P[1], d.P[2], d.L[0], d.L[1], d.L[2]);
  };
  write_diag(d0);
  const long long nseg = std::llround(t_end / diag), snap_every = snap > 0 ? std::llround(snap / diag) : 0;
  if (snap_every) h4nb::write_snapshot(out + "/snap_000000.snap", sim.state(), 0.0);
  for (long long k = 1; k <= nseg; ++k) {
    const h4nb::Stats s0 = sim.stats();
    const auto w0 = Clock::now();
    sim.advance_to(double(k) * diag);
    const double wall = since(w0);
    const h4nb::Stats s1 = sim.stats();
    const long long steps = s1.block_steps - s0.block_steps, active = s1.active_total - s0.active_total;
    std::fprintf(fp, "%.17g %.6f %lld %lld %.6e\n", sim.time(), wall, steps, active, double(active) * N / wall);
    if (sim.status() & h4nb::kNaN) {
      std::fprintf(stderr, "h4nb_run: NaN at t=%g\n", sim.time());
      return 2;
    }
    write_diag(sim.diagnostics());
    double dmin = 1e300, dmax = 0, dsum = 0;
    for (int lv : sim.levels()) {
      const double dt = c.dt_max / std::ldexp(1.0, lv);
      dmin = std::min(dmin, dt); dmax = std::max(dmax, dt); dsum += dt;
    }
    std::fprintf(ft, "%.17g %.6e %.6e %.6e %.3f\n", sim.time(), dmin, dmax, dsum / N,
                 steps ? double(active) / double(steps) : 0.0);
    if (snap_every && k % snap_every == 0) {
      char name[64];
      std::snprintf(name, sizeof name, "/snap_%06lld.snap", k / snap_every);
      h4nb::write_snapshot(out + name, sim.state(), sim.time());
    }
    for (FILE* f : {fe, fm, ft, fp}) std::fflush(f);
  }
  const unsigned st = sim.status();
  if (st & h4nb::kClosePair) std::fprintf(stderr, "warning: a pair came closer than r_close\n");
  if (st & h4nb::kDtUnderflow) std::fprintf(stderr, "warning: a particle wanted dt < dt_min (raise max_level)\n");
  std::printf("t=%g: max |dE/E| = %.3e\n", sim.time(), max_err);
  for (FILE* f : {fe, fm, ft, fp}) std::fclose(f);
  return 0;
} catch (const std::exception& e) {
  std::fprintf(stderr, "h4nb_run: %s\n", e.what());
  return 1;
}

// h4nb_bench: pair-interaction rate for a list of N (TZ 12: "benchmark results for different N").
// Usage: h4nb_bench [n=16384,131072,1024000] [devices=0] [eta=0.01] [segments=1]
#include <chrono>
#include <cstdio>
#include "args.hpp"
#include "disk.hpp"

using Clock = std::chrono::steady_clock;
static double since(Clock::time_point t) { return std::chrono::duration<double>(Clock::now() - t).count(); }

int main(int argc, char** argv) try {
  const Args a(argc, argv);
  h4nb::Config c;
  c.devices = a.ints("devices", "0");
  c.eta = a.num("eta", 0.01);
  c.dt_max = 1.0 / 16;
  const int segments = int(a.num("segments", 1));
  std::printf("%9s %4s %10s %12s %11s %10s %8s %12s\n", "N", "GPUs", "init_s", "init_pair/s", "GFLOP/s(60)",
              "step_s", "blocks", "step_pair/s");
  for (int n : a.ints("n", "16384,131072,1024000")) {
    const h4nb::Particles p = make_disk(n - 1, 0.5, 1.0, 10.0, 1);
    const double N = double(p.size());
    const auto t0 = Clock::now();
    h4nb::Simulation s(p, c);
    const double init = since(t0);
    const auto t1 = Clock::now();
    s.advance_to(c.dt_max * segments);
    const double step = since(t1);
    const h4nb::Stats st = s.stats();
    std::printf("%9d %4zu %10.3f %12.3e %11.1f %10.3f %8lld %12.3e\n", n, c.devices.size(), init, N * (N - 1) / init,
                60.0 * N * (N - 1) / init / 1e9, step, (long long)st.block_steps,
                double(st.active_total - static_cast<int64_t>(N)) * N / step);
  }
  return 0;
} catch (const std::exception& e) {
  std::fprintf(stderr, "h4nb_bench: %s\n", e.what());
  return 1;
}

## Gated optimisations (not tasks: do one only when its gate shows the need, and measure before and after with `h4nb_bench` and `test_gpu_vs_ref`)

| # | Optimisation | Gate |
|---|---|---|
| O1 | Fuse the predictor into the tile load of `force_kernel`: predict the sources while loading shared memory and drop `predict_kernel`. | `nsys` shows that `predict_kernel` uses > 10 % of the step time. |
| O2 | Tune `BI` (64/128/256), `#pragma unroll`, `__launch_bounds__` and the target of 4 blocks per SM in `split()`. | Task 7 step 1 is below 40 % of FP64 peak. |
| O3 | Sort the particles by level, or keep lists per level, so that the select pass and the predict pass skip inactive particles. | `DeviceSelect` + `predict_kernel` use > 10 % of the step time. |
| O4 | Remove the 2 host syncs per block step: use CUDA graphs, or compute `Tn` and the counts on the device. | The median N_active is < ~5k and the step time is dominated by latency. |
| O5 | Mixed precision: compute the relative position in FP64 and the pair math in FP32, and keep FP64 sums. **The TZ 4.4 forbids this. Ask the user first.** | The target GPUs are RTX class, and the energy acceptance runs still pass at 1e-8. |
| O6 | Pairs for close encounters: KS or chain regularisation (TZ 15.3). | `kClosePair`/`kDtUnderflow` appear in real runs, or `dt_min` causes stalls. |
| O7 | Multi-node: MPI with NCCL all-gather and reduce-scatter, keeping the same j-parallel layout. | The user needs more GPUs than one node has. |
| O8 | Exact restart: save `a, j, t, level` in the snapshot, version 2. | The user needs restarts that are bitwise exact (TZ 14.8). Today a restart from `read_snapshot` computes a, j again (a small, valid perturbation). |
| O9 | Per-GPU kernel and transfer times in `performance.dat`, with CUDA events. | The user asks for it (D9). |
