# A5. Zero acceleration gives a false kDtUnderflow

- Severity: MEDIUM
- Location: `src/hermite.cuh:136`
- Problem: a body exactly at the centre of a symmetric start: `eta_init * 0 / |j| = 0`. It starts at `max_level` and `kDtUnderflow` is set, but nothing is wrong.
- Fix: same guard as A1.

**Closed 2026-11-08:** `init_level()` returns level 0 with no status bit when `a = j = 0`, even if snap or crackle is nonzero. The old A1 check needed all four norms zero; a centre body with nonzero snap then got `dt = 0`, `max_level` and `kDtUnderflow`.
